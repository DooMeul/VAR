# 🚗 VAR - 피지컬 AI·블록체인 기반 3D 자동차 사고 복원 및 과실 산정 플랫폼

> 블랙박스가 못 본 8초, 물리 법칙이 증명합니다.

사고 순간의 주행 수치를 차량 안에서 바로 봉인하고, 클라우드의 디지털 트윈에서 3D로 복원해 과실을 수학적으로 계산하는 서비스 아이디어입니다.
이 저장소에는 해커톤 발표에서 서비스 흐름을 보여 주기 위해 만든 **인터랙티브 시연 페이지**가 들어 있습니다.

## 🎯 해결하려는 문제

| 문제 | 내용 |
|---|---|
| 블랙박스의 사각지대 | 화각 밖의 움직임, 야간 착시, 프레임 누락 때문에 영상만으로는 제동 시점과 속도를 증명하기 어렵습니다. |
| 불투명한 합의 관행 | 과실비율 분쟁이 길어지고, 억울해도 반박할 객관적인 근거가 부족합니다. |
| 자율주행 책임의 공백 | 운전자 과실인지 시스템 결함인지 가릴 공인된 도구가 아직 없습니다. |

<br>

## 🔄 서비스 흐름 (시연 4단계)

| 단계 | 내용 |
|---|---|
| ① 엣지 AI 트리거 | 충격이 감지되면 사고 전 6초~후 2초, 총 8초의 주행 수치(조향각·제동압·가속도·속도)만 잘라 암호화 |
| ② 블록체인 봉인 | 1초 단위 8개 블록을 차량 보안칩(HSM)으로 서명하고 해시 체인으로 연결해 위·변조 차단 |
| ③ 디지털 트윈 복원 | HD맵 위에서 10ms 단위로 사고 장면을 재구성하고, 타임라인과 센서 그래프를 함께 표시 |
| ④ 과실 연산 | 상대 차량이 끼어든 순간 확보된 거리와 충돌을 피하는 데 필요한 거리를 비교해 회피 가능성과 과실비율 계산 |

리포트는 **운전자 동의 + 법원 명령 + 보험사 요청**의 3중 열람키가 모두 맞아야 열리도록 설계했습니다.

<br>

## 🖥 시연 페이지 구성

- 서비스 소개와 문제 정의
- 사고 복원 시연: 4단계를 버튼과 타임라인으로 직접 넘겨 보거나 **자동 시연**으로 재생
  - 위·변조 시도 버튼으로 해시 체인이 끊어지는 모습 확인
  - 디지털 트윈 타임라인을 움직이면 장면과 그래프가 함께 변화
- 기존 사고 처리 과정과 VAR 도입 후 과정 비교
- 최신 차량·노후 차량·V2X 협력 복원 등 차종별 적용 방안
- 신뢰 구조(컨소시엄 블록체인, 3중 열람키, 서버리스)와 기대효과

- 화면 속 사고 시나리오, 차량 수치, 과실 계산은 이해를 돕기 위해 **과실비율 인정기준을 단순화한 시연용 가상 모델**입니다.
